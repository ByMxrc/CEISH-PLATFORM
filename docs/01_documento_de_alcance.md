# Sistema de Gestión de Evaluaciones CEISH

## 1. Descripción General

El sistema tiene como objetivo digitalizar el proceso de gestión, revisión y evaluación de investigaciones realizadas ante el Comité de Ética de Investigación en Seres Humanos (CEISH).

El sistema permitirá gestionar desde la solicitud inicial de investigadores hasta la evaluación final de una investigación, incluyendo:

- Registro y aprobación de investigadores.
- Gestión de investigaciones.
- Administración de anexos.
- Estratificación de riesgo.
- Asignación de miembros CEISH.
- Evaluaciones mediante listas de criterios.
- Gestión de observaciones y correcciones.
- Seguimiento histórico del proceso.


---

# 2. Objetivos

## Objetivo general

Crear una plataforma que permita controlar digitalmente el flujo de revisión ética de investigaciones.


## Objetivos específicos

- Reducir procesos manuales.
- Mantener trazabilidad de decisiones.
- Gestionar documentos asociados.
- Facilitar la asignación de evaluadores.
- Mantener historial de revisiones.


---

# 3. Usuarios del sistema

El sistema contará con tres tipos principales de usuarios:


## Investigador

Persona que presenta una investigación para evaluación.

Puede ser:

- Investigador interno.
- Investigador externo.


Funciones:

- Solicitar creación de cuenta.
- Crear investigaciones.
- Subir anexos requeridos.
- Registrar investigadores participantes.
- Responder observaciones.
- Enviar correcciones.


---

## Miembro CEISH

Usuario encargado de participar en la revisión ética.

Puede ser:

- Miembro interno.
- Miembro externo.


Un miembro puede adquirir diferentes responsabilidades dependiendo de la investigación.


Responsabilidades:

### Estratificador

Determina el nivel de riesgo.


Disponible únicamente para miembros internos.


### Evaluador

Realiza evaluación documental.


Disponible para miembros internos y externos.


---

## Administrador

Usuario encargado de controlar el sistema.


Funciones:

- Aprobar usuarios.
- Gestionar investigaciones.
- Asignar miembros CEISH.
- Administrar anexos.
- Supervisar evaluaciones.
- Realizar revisiones cuando sea necesario.


---

# 4. Fuera del alcance inicial

No se contempla inicialmente:

- Inteligencia artificial.
- Automatización avanzada.
- Integraciones externas.
- Firma digital.
- Reportería avanzada.


Estos módulos pueden agregarse posteriormente.
